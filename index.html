Note Growth

人気上位10件の調査依頼

  1. note でキーワードを検索し、並び順を「人気」にする
  2. 上位の記事URLを、上から順に1行1件で貼る（最大10件）
  3. 保存すると data/requests/ に依頼が残る。記事ページの読み取りは Claude Code（進行役）か PC で行う

得意分野（アプリ開発・デモアプリ・将棋・スロット・テニス・Switch 2）のキーワードに限ります。

設定

Fine-grained token を使い、対象リポジトリは note-growth-team だけ、権限は「Contents: Read and write」だけにしてください。 トークンはこの端末の中（ブラウザ）にだけ保存され、GitHub 以外には送りません。端末を人に貸すときは「トークンを消す」を押してください。
